Antes de instalar

Compatibilidad

Compatible con PES 2018 de PS4 y con la versión de PS4 ejecutada en PS5. La importación se realiza mediante la carpeta WEPES.

Instalación

  • Hacé una copia de seguridad de los datos editados antes de importar.
  • Usá una memoria USB en formato compatible y respetá la estructura de la carpeta WEPES.
  • Seguí el orden del tutorial para evitar equipos o imágenes duplicadas.

Problemas comunes

Faltan kits o escudos

Revisá el espacio disponible para imágenes y volvé a importar los archivos que hayan fallado.

Aparecen equipos duplicados

La causa más frecuente es importar sobre otra base. Restaurá la copia de seguridad y realizá una instalación limpia.

Preguntas frecuentes

¿Funciona en PS5?

Sí, usando la versión de PS4 de PES 2018 ejecutada en PS5.

¿Tengo que instalar la V1 primero?

Consultá el tutorial enlazado antes de importar: allí se indica el orden recomendado para esta publicación.
