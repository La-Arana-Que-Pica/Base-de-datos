Qué incluye

  • Licencia equipos pendientes.
  • Completa kits, escudos y datos editables.
  • Funciona como complemento del Option File base.

Antes de instalar

Disponible para PC, PS4 y PS5. Debe combinarse con una base compatible.

Hacé una copia de seguridad antes de eliminar archivos.

Estas instrucciones son exclusivas de este complemento, no de las demás descargas de Spider Patch.

  1. Consultá el tutorial del complemento y comprobá que corresponde a tu base.
  2. Instalá el complemento siguiendo el procedimiento del video.
  3. Después, eliminá la carpeta WEPES según el procedimiento del tutorial, una vez realizada la copia de seguridad.
