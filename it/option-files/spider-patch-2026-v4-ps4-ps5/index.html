Compatibilità con PlayStation

I file dell'Option File sono destinati a PS4 e a PS5 tramite la versione PS4 di PES 2018. Entrambe le console usano lo stesso download di Spider Patch V4 per PlayStation. Non usare i file per PC per questa installazione.

Installazione su PS4 e PS5 (riepilogo)

  1. Scarica il file Spider Patch V4 per PS4/PS5 ed estraine il contenuto.
  2. Copia la cartella WEPES inclusa nel pacchetto nella directory principale di una chiavetta USB compatibile con la console.
  3. Apri PES 2018 ed entra nell'editor dei dati per importare il contenuto dell'Option File.
  4. Esegui l'importazione di competizioni e squadre secondo le opzioni indicate nel tutorial di questa versione.
  5. Controlla le rose e le squadre al termine dell'importazione.

Prima di importare l'Option File

Importante: ti serve PES 2018 su PlayStation. Si consiglia di fare un backup dei dati di modifica esistenti prima di sovrascriverli. Le opzioni di importazione possono influire sui dati personalizzati; segui il tutorial della V4 per scegliere le opzioni corrette. Il Face Pack in RAR è un componente aggiuntivo per PC, non un download per PS4/PS5.
