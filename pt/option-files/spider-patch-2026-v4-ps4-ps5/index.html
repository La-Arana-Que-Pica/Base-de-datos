Compatibilidade com PlayStation

Os arquivos do Option File são destinados ao PS4 e ao PS5 por meio da versão de PS4 do PES 2018. Os dois consoles usam o mesmo download do Spider Patch V4 para PlayStation. Não use os arquivos de PC para fazer esta instalação.

Instalação no PS4 e PS5 (resumo)

  1. Baixe o arquivo Spider Patch V4 para PS4/PS5 e extraia o seu conteúdo.
  2. Copie a pasta WEPES incluída no pacote para a raiz de um pendrive compatível com o console.
  3. Abra o PES 2018 e entre no editor de dados para importar o conteúdo do Option File.
  4. Faça a importação de competições e times de acordo com as opções indicadas no tutorial desta versão.
  5. Confira os elencos e os times assim que a importação terminar.

Antes de importar o Option File

Importante: você precisa do PES 2018 no PlayStation. Recomenda-se fazer backup dos dados de edição existentes antes de sobrescrevê-los. As opções de importação podem afetar dados personalizados; siga o tutorial da V4 para escolher as opções corretas. O Face Pack em RAR é um complemento para PC, não um download de PS4/PS5.
