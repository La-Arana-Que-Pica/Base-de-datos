Acerca del proyecto

LAqP.website existe para ordenar recursos utiles de PES 2018 actualizado: stats, caras, plantillas, equipos, ligas, tutoriales, herramientas y descargas.

La idea es que cualquier jugador pueda consultar datos modernos y usarlos como referencia para editar PES 2018 sin depender de informacion suelta o desactualizada.

LAqP Proyecto de Agustin Segade Stats, caras, tutoriales y base de datos

Quién está detrás del proyecto

LAqP es el autor que mantiene este hub independiente de PES 2018. El contenido combina trabajo propio, organizacion de datos, tutoriales de instalacion, creacion de caras, kits, tacticas, plantillas y una base consultable para editar el juego con datos actuales.

Autoría de caras y uso permitido

Todas las caras publicadas en esta web son de autoría de LAqP. Podés usarlas en Option Files o parches dando créditos claros al proyecto, pero no se permite republicarlas en YouTube ni presentarlas como contenido propio.

Proyecto independiente

LAqP.website es un proyecto independiente creado por fans. No está afiliado, patrocinado ni respaldado oficialmente por Konami, eFootball o Pro Evolution Soccer.
