Acerca de LAqP

LAqP.website es la web oficial de La Araña Que Pica, un proyecto creado para reunir descargas, tutoriales, guías, caras de jugadores y recursos relacionados con PES 2018.

El objetivo es ordenar la información importante del proyecto para que la comunidad encuentre versiones, instrucciones y datos de forma rápida.

LAqP Proyecto y comunidad de PES 2018 Option Files, tutoriales y base de datos

Quién está detrás del proyecto

LAqP es un proyecto independiente y una comunidad dedicada a mantener vivo PES 2018 con Option Files, tutoriales de instalación, creación de caras, kits, actualizaciones y una base de datos consultable.

Autoría de caras y uso permitido

Todas las caras publicadas en esta web son de autoría de LAqP. Podés usarlas en Option Files o parches dando créditos claros al proyecto, pero no se permite republicarlas en YouTube ni presentarlas como contenido propio.

Proyecto independiente

LAqP.website es un proyecto independiente creado por fans. No está afiliado, patrocinado ni respaldado oficialmente por Konami, eFootball o Pro Evolution Soccer.

Contacto y comunidad

Los comentarios, reportes de errores y sugerencias ayudan a mejorar cada nueva versión del contenido.
