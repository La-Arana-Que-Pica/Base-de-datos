Que hace esta herramienta

Scouting cruza datos del Option File LAqP para sugerir jugadores que encajen con el nivel de tu club. La idea no es listar solo medias altas, sino ayudarte a encontrar perfiles utiles: suplentes baratos, titulares posibles, juveniles con margen o refuerzos para una posicion concreta.

Usa media, edad, posicion y equipo actual para armar una lista corta.

Como usar Scouting

Primero elegi la liga y el club de tu partida. Despues selecciona una posicion o perfil. Si estas jugando una Liga Master larga, conviene guardar candidatos y comparar edad, media actual y rol antes de decidir.

Preguntas frecuentes

Las recomendaciones son oficiales?

No. Son recomendaciones de LAqP basadas en los datos disponibles del Option File y criterios de encaje para Liga Master.

Por que no aparece un jugador?

Puede no estar en la base publicada, no cumplir filtros activos o quedar fuera por nivel relativo al club elegido.

Sirve para cualquier Option File?

Funciona mejor con la base de datos de LAqP, porque las recomendaciones salen de esos jugadores, equipos y medias.
