About LAqP.website

Proyecto independiente sobre PES 2018 actualizado: Option Files, guias, Scouting y base de datos.

Que es LAqP

LAqP reúne descargas, guias, tutoriales y datos del Option File en un solo lugar.

Foco editorial

  • Option Files de PES 2018 para temporadas actuales.
  • Guias de instalacion, kits, caras, Sider, CPK y problemas comunes.
  • Base de datos de jugadores, equipos, ligas, stats, posiciones y apariencia.
  • Scouting y recomendaciones para descubrir jugadores utiles segun club, liga y perfil.

Proyecto independiente

LAqP.website no es un sitio oficial de Konami ni esta afiliado con clubes, ligas o marcas.
