How the PC edition is distributed

The main Spider Patch V4 package for PC comes in three required RAR parts. Face Pack LAqP PES 2018 V1 is an optional add-on and is also delivered in three RAR parts. The Face Pack is not included in the main download.

PC installation (summary)

  1. Download the three parts of the main package and keep them together in the same folder. Start the extraction from part 1 so the remaining parts are used.
  2. Open the folder with the extracted content and copy the files from the «Dentro de la carpeta del juego» (inside the game folder) folder into the root folder where PES 2018 is installed.
  3. In the package's «Documentos» folder you will find «Save»: copy it to Documents\KONAMI\PRO EVOLUTION SOCCER 2018 to update the game data.
  4. Run PES 2018 DP File List Generator 1.4.exe, included in the patch files, and enable the Data Packs in order together with the patch files.
  5. If you install the optional Face Pack, download and extract its three parts, follow the add-on's specific procedure and enable it in the generator as well.
  6. Follow the V4 video tutorial to review the full installation and the correct generator options.

Before installing

Important: you need PES 2018 for PC. Keep a copy of your original files and your edit data before replacing them. Do not confuse the three required parts of the main package with alternative links; you need all three to extract it correctly. The Face Pack is optional and exclusive to the PC distribution.
