What's included

  • Licenses pending teams.
  • Completes kits, badges and editable data.
  • Works as an add-on to the base Option File.

Before installing

Available for PC, PS4 and PS5. It must be combined with a compatible base.

Make a backup before deleting files.

These instructions apply only to this add-on, not to the other Spider Patch downloads.

  1. Check the add-on's tutorial and make sure it matches your base.
  2. Install the add-on following the procedure shown in the video.
  3. Then, once the backup is done, delete the WEPES folder as described in the tutorial.
