What's included

  • V1 content reviewed for the new release.

Leagues: Premier League, LaLiga, Serie A, Ligue 1, Liga Argentina, Brasileirão, Copa Libertadores.

Before installing

Compatible with PES 2018 on PS4 and with the PS4 version running on PS5. The import is done through the WEPES folder.

  1. Back up your edited data before importing.
  2. Use a USB drive in a compatible format and keep the WEPES folder structure.
  3. Follow the tutorial order to avoid duplicated teams or images.

Frequently asked questions and problems

Common problems

Kits or badges are missing

Check the space available for images and import again the files that failed.

Duplicated teams appear

The most common cause is importing over another base. Restore your backup and do a clean installation.

Frequently asked questions

Does it work on PS5?

Yes, using the PS4 version of PES 2018 running on PS5.

Do I have to install V1 first?

Check the linked tutorial before importing: it shows the recommended order for this release.
