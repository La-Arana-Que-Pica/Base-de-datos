Option File vs parche en PES 2018: diferencias y cuál conviene

Conocé las diferencias entre un Option File y un parche de PES 2018, qué modifica cada uno y cuál conviene instalar en PC, PS4 o PS5.

Por Agustín Segade·Publicado el 23/05/2026·2 min de lectura

Recursos útiles

↗HerramientaCómo instalar un Option File en PES 2018↗HerramientaCPK vs Sider: diferencias y usos

Los Option Files y los parches sirven para actualizar PES 2018, pero no funcionan de la misma manera. La diferencia más importante es qué archivos modifican y en qué plataforma podés utilizarlos.

Qué es un Option File de PES 2018

Un Option File es un conjunto de datos creados o modificados con el editor del juego. Permite actualizar equipos, plantillas y otros elementos que PES deja editar sin reemplazar sus archivos internos.

  • Nombres de equipos y competiciones.
  • Escudos y kits importados.
  • Jugadores, plantillas, estadísticas y formaciones.
  • Equipos y ligas editables del juego.
Ideal para consolas

En PS4 y PS5, un Option File se instala desde el menú Editar de PES 2018. No necesitás modificar los archivos internos de la consola.

Qué es un parche para PES 2018

Un parche puede cambiar archivos internos del juego. En PC se utilizan métodos como CPK o Sider para instalar contenido que el editor de PES no permite modificar.

  • Caras y minifaces personalizadas.
  • Menús, imágenes y música del juego.
  • Kits de equipos licenciados y elementos gráficos.
  • Estadios, marcadores, cánticos y otros mods, según su compatibilidad.
No todos los parches incluyen lo mismo

Un parche puede traer una sola mejora o muchas. Antes de instalarlo, revisá qué incluye, qué versión de PES necesita y si es compatible con otros mods.

Diferencia principal entre Option File y parche

El Option File aprovecha las opciones del editor interno. El parche puede ir más allá y reemplazar recursos que el juego no deja editar desde sus menús.

  • Option File: modifica datos y recursos admitidos por el editor de PES.
  • Parche: puede modificar archivos del juego, principalmente en PC.
  • Ambos pueden actualizar equipos y uniformes, pero mediante métodos diferentes.

Cuál conviene instalar según tu plataforma

En PS4 y PS5

Si jugás en una consola normal, elegí un Option File compatible con tu versión de PES 2018. Es el método habitual para importar equipaciones, escudos y cambios de equipos desde el propio juego.

En PC

Podés usar Option Files para editar equipos y plantillas, parches para modificar archivos internos o una combinación de ambos. Lo importante es comprobar que las versiones sean compatibles.

¿Puedo combinar un Option File con un parche?

Sí, en PC pueden complementarse. Por ejemplo, un Option File puede actualizar las plantillas y un parche puede aportar minifaces y menús nuevos.

Cuidá la compatibilidad

Antes de mezclar mods, hacé una copia de seguridad de tus archivos y seguí las instrucciones de cada autor. Dos parches que modifican el mismo recurso pueden entrar en conflicto.

Por dónde empezar

Si querés actualizar PES 2018 desde el editor, empezá por la guía para instalar un Option File.

Si jugás en PC y querés agregar minifaces, menús o gráficos, también te conviene conocer la diferencia entre CPK y Sider.

Dudas adicionales

¿Option File y parche son lo mismo?

No. Un Option File guarda cambios del editor del juego; un parche puede reemplazar o agregar archivos internos, especialmente en PC.

¿Se pueden instalar parches CPK en PS4 o PS5 normales?

Este tipo de parche está pensado para PC. En PS4 y PS5 sin modificaciones del sistema lo habitual es instalar Option Files desde el editor de PES.

¿Se pueden combinar un Option File y un parche en PC?

Sí, siempre que sean compatibles. El Option File puede aportar equipos y plantillas, mientras que el parche puede añadir caras, minifaces, menús y otros recursos.

¿Qué opción conviene para actualizar equipos y kits?

En consola, normalmente un Option File. En PC, depende de si buscás únicamente datos editables o también modificaciones de archivos internos.
