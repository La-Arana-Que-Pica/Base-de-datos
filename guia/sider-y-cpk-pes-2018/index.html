CPK vs Sider en PES 2018: diferencias y cuándo usar cada uno

Entendé qué son CPK, Sider y LiveCPK en PES 2018 para PC, cómo se cargan los mods y cuál método conviene para instalar o probar cambios.

Por Agustín Segade·Publicado el 20/05/2026·3 min de lectura

Recursos útiles

↗HerramientaOption File vs parche en PES 2018

Si estás instalando mods en PES 2018 para PC, seguramente encontraste archivos CPK y herramientas como Sider o LiveCPK. No son lo mismo: cada método carga el contenido de una forma distinta y conviene para tareas diferentes.

Qué es un archivo CPK

Un CPK es un archivo que reúne recursos del juego, como minifaces, caras, kits o menús. Se utiliza para instalar mods empaquetados.

  1. Colocá el CPK en la carpeta download de PES 2018.
  2. Abrí una herramienta compatible, como DpFileList Generator.
  3. Incluí el nuevo CPK junto con los que ya utilizás y generá DpFileList.bin.
  4. Iniciá el juego y comprobá que se cargó correctamente.
Ventaja del CPK

Una vez instalado, no necesitás mantener abierto un programa extra para cargar ese contenido.

Qué es Sider

Sider es un programa externo que funciona junto con PES 2018 en PC. Permite cargar archivos y módulos adicionales sin depender exclusivamente de los CPK.

Para utilizarlo, tenés que tener una versión compatible y seguir su configuración. No todos los mods de Sider funcionan de la misma forma ni requieren los mismos pasos.

Qué es LiveCPK y por qué sirve para editar

LiveCPK es una función de Sider que permite cargar archivos modificados desde carpetas. Es útil cuando estás probando algo y todavía no querés empaquetarlo en un CPK.

Por ejemplo, si corregís una miniface, podés cambiar el archivo de trabajo y volver a probarlo sin crear un CPK nuevo cada vez. Así ahorrás tiempo durante la edición.

Necesita configuración

LiveCPK no funciona solo: forma parte de una instalación de Sider que debe estar configurada para el juego y el contenido que vas a cargar.

Qué son los módulos o servidores de Sider

Sider también puede utilizar módulos para funciones más avanzadas. Algunos permiten cambiar recursos según el contexto del partido, como un marcador diferente para cada competición.

Esto es distinto de reemplazar un archivo fijo con un CPK: el módulo puede elegir qué recurso mostrar mientras se juega.

CPK o Sider: cuál conviene elegir

  • CPK: para dejar un mod empaquetado e instalado de forma estable.
  • Sider con LiveCPK: para probar cambios y trabajar sobre archivos sueltos.
  • Módulos de Sider: para funciones dinámicas que requieren algo más que reemplazar un archivo.

No hace falta elegir un único método para todo. Podés editar y probar con LiveCPK y, cuando termines, preparar un CPK si te resulta más cómodo.

Qué revisar si un mod no aparece

  1. Comprobá que el mod sea compatible con tu PES 2018 y con la versión de Sider que uses, si corresponde.
  2. Si es un CPK, verificá que esté en download y figure en el DpFileList.bin generado.
  3. Si usás LiveCPK, revisá las carpetas y la configuración de Sider.
  4. Si varios mods reemplazan el mismo archivo, comprobá cuál tiene prioridad en la carga.
Hacé copias de seguridad

Antes de modificar DpFileList.bin o la configuración de tus mods, guardá una copia. Evitá mezclar paquetes incompatibles.

La recomendación de LAqP

Para aprender y probar cambios rápidamente, LiveCPK puede ser muy útil. Para un pack terminado que quieras tener instalado sin ejecutar otro programa, el CPK suele ser la opción más sencilla.

Si todavía no sabés qué modifica cada archivo, consultá primero las diferencias entre Option File y parche.

Dudas adicionales

¿CPK y Sider hacen lo mismo?

Ambos pueden servir para cargar mods, pero CPK es un archivo empaquetado y Sider es un programa que se ejecuta con el juego.

¿Qué es LiveCPK?

Es una función de Sider que permite cargar archivos desde carpetas sin tener que crear un CPK nuevo para cada cambio.

¿Qué conviene para probar minifaces o gráficos?

Si tenés Sider y LiveCPK correctamente configurados, es práctico para probar modificaciones sin volver a empaquetarlas.

¿Qué pasa si dos mods cambian el mismo archivo?

Puede prevalecer uno según el método y el orden de carga. Conviene revisar las prioridades y evitar duplicaciones.
