Cómo instalar un Option File en PES 2018

Guía paso a paso para instalar un Option File en PES 2018 en PC, PS4 y PS5: carpeta WEPES, importación de campeonatos, equipos, estructura de ligas y guardado.

Introduccion

Instalar un Option File en PES 2018 es un proceso bastante simple, pero es importante seguir bien los pasos para que el juego detecte correctamente los archivos y no aparezcan errores durante la importación.

Esta guía está pensada principalmente para PES 2018, aunque también puede servir como referencia para otros PES modernos, ya que el sistema de importación suele tener una estructura similar.

Qué es un Option File

Un Option File es un archivo que incluye datos editados desde el editor interno del juego. Sirve para modificar equipos, competiciones, kits, escudos, plantillas, nombres, formaciones y otros elementos editables.

Es importante aclarar que un Option File se limita a lo que permite cambiar el modo Editar. No modifica archivos internos del juego como si lo hace un parche. Por eso es uno de los métodos más utilizados en PS4 y PS5, y también puede usarse en PC.

Preparar la carpeta WEPES

Después de descargar el Option File que quieras instalar, lo primero que tenés que hacer es extraer el archivo si viene comprimido en formato RAR o ZIP.

Una vez extraído, deberías encontrar una carpeta llamada WEPES. Es muy importante no cambiarle el nombre: la carpeta debe llamarse exactamente WEPES, porque si tiene otro nombre el juego no va a detectar los archivos que hay adentro.

Instalación en PC

Si jugás en PC, tenés que copiar la carpeta WEPES dentro de la carpeta de PES 2018 ubicada en Documentos.

La ruta normalmente es: Documentos/KONAMI/PRO EVOLUTION SOCCER 2018/.

Con eso, los archivos ya deberían aparecer dentro del juego para poder importarlos.

  • Extraer el Option File descargado.
  • Copiar la carpeta WEPES.
  • Ir a Documentos/KONAMI/PRO EVOLUTION SOCCER 2018/.
  • Pegar ahí la carpeta WEPES.
  • Abrir PES 2018.
  • Entrar al modo Editar.

Instalación en PS4 y PS5

Si jugás en PS4 o PS5, necesitás usar un pendrive. El USB debe estar formateado en FAT32 para que la consola pueda leer correctamente los archivos.

Dentro del pendrive tenés que pegar la carpeta WEPES en la carpeta principal del USB, no dentro de otra carpeta. También es importante expulsar el USB antes de desconectarlo de la computadora para evitar que se dañe algún archivo durante la transferencia.

  • Conectar un USB a tu PC o laptop.
  • Formatearlo en FAT32 si es necesario.
  • Copiar la carpeta WEPES.
  • Pegarla en la carpeta principal del USB.
  • Expulsar el USB de forma segura desde la computadora.
  • Conectar el USB a la PS4 o PS5.
  • Abrir PES 2018.
  • Entrar al modo Editar.

Importar campeonatos

A partir de este punto, el proceso es el mismo en PC, PS4 y PS5. Dentro del juego, entra en: Editar -> Administrador de datos -> Importar/Exportar -> Importar campeonatos.

Esta opción sirve para importar los nombres y logos reales de las competiciones incluidas en el Option File. Podés seleccionar los campeonatos que quieras importar. Si querés seleccionar todos de una vez, podés hacerlo con cuadrado en PlayStation o con A en PC, dependiendo de tu configuración.

Después te va a aparecer una opción llamada Sobreescribir archivos con el mismo nombre. Es recomendable activarla, sobre todo si ya tenías otro Option File instalado antes, para evitar duplicados o conflictos con imágenes anteriores.

Una vez seleccionada la opción, le das a OK y esperás a que se importen los campeonatos.

Importar equipos

Después de importar los campeonatos, volve al menú de Importar/Exportar y entra en Importar equipos.

Esta opción importa los equipos incluidos dentro del Option File. Igual que antes, podés seleccionar los equipos que quieras importar o seleccionar todos de una vez con cuadrado o A.

Antes de confirmar, el juego te va a mostrar algunas opciones importantes.

Opciones al importar equipos

Sobreescribir archivos con el mismo nombre es la misma opción que aparece al importar campeonatos. Sirve para reemplazar archivos anteriores si ya existía otro con el mismo nombre. En general, conviene activarla para evitar duplicados o conflictos con imágenes viejas.

Aplicar datos de jugadores y plantillas depende mucho del Option File que estés instalando. Si solo querés importar equipaciones, escudos, nombres o elementos externos a los jugadores, podés dejarla desmarcada.

Pero si el Option File actualiza el juego, cambia plantillas, agrega jugadores, modifica stats o reemplaza equipos completos, tenés que marcar esta opción. En la mayoría de Option Files actuales, sobre todo los que buscan actualizar PES 2018 a una temporada moderna, es una opción fundamental.

Elegir equipo al que importar los datos permite elegir manualmente sobre qué equipo del juego se va a aplicar cada archivo del Option File. Puede servir si querés hacer una instalación personalizada, pero si estás instalando un Option File completo, normalmente conviene seguir las instrucciones del creador del pack.

Esperar la instalación

Cuando confirmes la importación de equipos, toca esperar. Si el Option File tiene muchos equipos, puede tardar bastante.

En algunos casos puede demorar más de 30 minutos, así que conviene tener paciencia y no cerrar el juego durante el proceso.

Configurar la estructura de campeonatos

Una vez importados los campeonatos y equipos, todavia puede faltar acomodar la estructura de las ligas. Para eso, desde el modo Editar entra en Estructura de campeonatos.

Ahí tenés que ordenar los equipos dentro de sus ligas correspondientes, según indique el Option File que estés instalando.

También podés entrar en Tamaño de sorteo para modificar la cantidad de equipos que tienen algunas ligas genéricas del juego, como PLA, PEU y PAS. Esto es importante porque muchos Option Files usan esas ligas para crear competiciones nuevas o reemplazar equipos genéricos.

Guardar los datos editados

Cuando termines de importar todo y acomodar las ligas, falta un paso clave: guardar.

Tenés que volver a Administrador de datos -> Guardar. Después confirmás que querés sobrescribir los datos editados y esperás a que el juego termine de guardar.

No salgas del modo Editar sin guardar, porque podrías perder los cambios y tener que repetir parte del proceso.

Error comun: no se guardan los cambios

A algunos usuarios les pasa que, después de importar un Option File grande, el juego no guarda correctamente todos los cambios. Una posible solución es instalar los equipos de a poco.

Por ejemplo, importas la mitad de los equipos, guardas los datos editados, importas la otra mitad y volves a guardar. Es un poco más lento, pero puede evitar errores cuando el Option File tiene muchos equipos o muchas imágenes.

Preguntas frecuentes

La carpeta tiene que llamarse WEPES?

Sí. El juego busca una carpeta llamada exactamente WEPES. Si tiene otro nombre, PES 2018 puede no detectar los archivos.

Tengo que activar Aplicar datos de jugadores y plantillas?

Si el Option File cambia plantillas, jugadores, stats o equipos completos, sí. Si solo importa kits o escudos, puede no ser necesario.

Qué hago si no se guardan todos los cambios?

Proba importar por tandas: primero una parte de los equipos, guardas, después importas el resto y volves a guardar.
