Ayuda, contacto y políticas de LAqP

Información útil sobre descargas, instalación, uso de la web, privacidad y créditos del contenido.

¿Cómo descargo la última versión?

Entrá en Option Files y usá el botón de descarga de la versión correspondiente a tu juego y plataforma.

¿Dónde veo tutoriales de instalación?

La sección Tutoriales reúne guías paso a paso para instalar y configurar el Option File.

¿Cómo busco jugadores, equipos o ligas?

En Base de datos podés entrar a Ligas, Equipos o Jugadores. Los favoritos quedan guardados dentro de esa sección.

¿Los datos se actualizan por CSV?

Sí. Las descargas y los datos principales se mantienen con archivos del proyecto para no romper la estructura de la base.

¿Puedo usar o republicar las caras?

Las caras publicadas en esta web son de autoría de LAqP. Se pueden usar en Option Files o parches dando los créditos correspondientes, pero no se permite republicarlas en YouTube u otras plataformas como contenido propio.

Contacto

Para consultas, reportes o sugerencias, usá las redes públicas del proyecto o el canal de YouTube.

Política de privacidad

Esta web no requiere crear una cuenta. Puede guardar favoritos y preferencias de idioma en el navegador. También usa Google Analytics para medir visitas, páginas consultadas y rendimiento general del sitio de forma agregada.
