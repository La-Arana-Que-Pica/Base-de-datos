Ayuda / FAQ

Respuestas rapidas para descargar, instalar y explorar la base de datos del Option File.

Como descargo la ultima version?

Entra en Option Files y usa el boton de descarga de la version correspondiente a tu juego y plataforma.

Donde veo tutoriales de instalacion?

La seccion Tutoriales reune guias paso a paso para instalar y configurar el Option File.

Como busco jugadores, equipos o ligas?

En Base de datos puedes entrar a Ligas, Equipos o Jugadores. Los favoritos quedan guardados dentro de esa seccion.

Los datos se actualizan por CSV?

Si. Las descargas y los datos principales se mantienen actualizados para la comunidad.

Contacto

Para consultas, reportes o sugerencias, usa el canal de YouTube o las vias de contacto que compartas con la comunidad.

Politica de privacidad

Esta web usa datos locales del proyecto y puede guardar favoritos en el navegador del usuario. No se requiere crear una cuenta para consultar la base de datos.
